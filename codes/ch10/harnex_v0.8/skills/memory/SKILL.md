name: memory
description: 记住用户的长期偏好与事实，或回忆之前记住的内容。当用户说「记住」「以后都」「我们项目用」「上次我提到」时使用。
---

## 记住
当用户表达一条稳定事实或偏好时（比如「我们项目用 pytest」），
调用 shell 执行 `harnex memory set <key> "<内容>"`。
key 用简短英文，如 `test_framework`。

## 回忆
需要用户的偏好或历史信息时，先执行 `harnex memory get`，
不要凭空猜测用户的习惯。

## 边界
不要把一次性的、临时的事当成长期记忆（「今天改登录」不进库）。
用户的明确纠正优先级最高，直接覆盖旧 key。
