## 从一个真实的体验落差说起

周一的早上，你打开某个 AI 聊天网页，输入：

> 帮我安排一下周末去杭州旅游行程。

它很快回了一屏内容：六个值得去的景点、三家酒店、几条美食街，末尾还加了句「祝您旅途愉快」。

然后呢？你关掉窗口，打开天气、打开购票 App、打开日程表 —— **安排行程这件事你并没有办完，只是得到了一份建议。**

景点、酒店、美食街都列出来了。天气还是你去查，票还是你去订，日程还是你去改。**它能生成内容，但没有替你做成一件事。**

这一章我们就顺着这个缺口往下看：它差在哪，要补上什么，才能真的替你办事。代码留到后面再写，这里先把边界说清楚。

读完这一章，你要能回答四个问题：

1. Agent 是什么？它和 Chatbot、Workflow、RPA 差别在哪？
2. Harness 是什么？为什么同一个模型能长出不同的产品？
3. 一个需求该用 Agent、普通程序、Workflow，还是先不自动化？
4. 这本书准备带你走到哪？贯穿项目又是什么？

我们先从三类常见做法看起。把它们分清楚，Agent 是什么就清楚了。
